# Triage Labels

这些 skills 用五个规范 triage roles 来表达状态。这份文件把这些角色映射到本仓库 issue tracker 中实际使用的 label 字符串。

| mattpocock/skills 中的 Label | 我们 tracker 中的 Label | 含义                     |
| ----------------------------- | ------------------------ | ------------------------ |
| `needs-triage`                 | `needs-triage`            | 维护者需要评估这个 issue    |
| `needs-info`                    | `needs-info`               | 正在等待报告者提供更多信息    |
| `ready-for-agent`               | `ready-for-agent`          | 已完全说明清楚，可以交给一个 AFK agent |
| `ready-for-human`               | `ready-for-human`          | 需要人类来实现              |
| `wontfix`                       | `wontfix`                  | 不会被处理                 |

当某个 skill 提到一个角色时（例如"apply the AFK-ready triage label"），使用这张表里对应的 label 字符串。

编辑右边这一列，改成你实际使用的词汇。
